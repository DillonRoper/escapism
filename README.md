// Planned Features //
- Procedurally generated NPCs with complex priorities (health, occupation, relations, etc.) and personalities based on the OCEAN model
- Chunk-based rendering and simulation
- Global economy
- Political and cultural interations
- Disasters
- Vast selection of occupations (farming, mining, guarding, etc.)

// Summary //
I want Escapism to be the "ultimate RPG" in the sense that players should be allowed to do whatever they want without feeling limited or powerless.
The environment will be fantasy inspired, with dragons, magic, dungeons, kingdoms, and even some rarer parts of the fantasy genre like vampires.
